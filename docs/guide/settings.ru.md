# Настройки и всё остальное

[English](settings.md) | **Русский**

## Окно настроек

Все настройки — в окне **Настройки** (шестерёнка вверху). Сверху — общие
разделы: **Общие** (язык, тема, Autonomi, сборка лаунчера, обновления,
данные), **Игры** (какие игры в переключателе, свои игры), **Аддоны**
(скрытые теги, теги на странице аддона, обновление репозиториев, разделы
списка), **Экспериментальное** (плеер, прогресс, защита сохранений). Ниже, под
выбором **игры**, — её разделы: **Папка игры**, **Запуск** (сборки) и
**Серверы**. Игру можно выбрать прямо в окне — игру лаунчера это не меняет.
Кнопки настроек на вкладках открывают нужный раздел.

## Первый запуск

Один раз показывается мастер:

1. **язык и тема** — сразу выбран язык системы, если для него есть перевод;
2. **репозиторий** из `pointer.txt` — скачать и подключить его или нет;
3. **игры** — какие показывать и какие свои игры добавить из
   `another_games.json`; затем, по желанию, папка и исполняемый файл каждой
   игры (найденные подставляются сами);
4. **экспериментальные функции** — плеер, прогресс, защита сохранений.

## Папка игры

Папка, где лежат файлы игры (`srb2.pk3`, `bios.pk3`…; на Linux обычно
подставляется сама). Игра запускается с ней как с рабочей папкой, поэтому
`config.cfg`, сохранения и папка загрузок берутся из неё, даже если сборки
лежат в другом месте. На Windows не выбирайте папку внутри
`C:\Program Files`: туда нельзя записывать аддоны без прав администратора.

**Скрытые папки** (там же, у каждой игры свои): аддоны из этих папок не
показываются в «Других загрузках» и «В папке игры»; аддоны из репозиториев —
показываются. Папка внутри папки игры хранится относительно неё.

## Язык и тема

Языки: English, русский, украинский, немецкий, испанский, португальский
(бразильский). Пока язык не выбран, берётся язык системы. Как добавить
язык — в [translations.ru.md](../translations.ru.md).

Темы: четыре встроенные и шесть в папке `themes` (Ocean, Ruby, Gold, Steel,
Midnight, светлая Daylight); свои — в редакторе. Подробно — в
[themes.ru.md](../themes.ru.md).

## Уведомления

Кнопка с колокольчиком в шапке (порядок: уведомления, загрузки, настройки);
число — сколько новых.

- **Репозиторий обновился** — какие аддоны появились и у каких новые версии.
- **Вышло обновление аддона** — у скачанного аддона текущей игры есть версия
  новее. О каждой версии — один раз (лаунчер помнит и после перезапуска).
- **Защита сохранений** — сохранение восстановлено или повреждено без копии.

## Обновления лаунчера

Новые версии берутся из
[релизов на GitHub](https://github.com/Sirexer/SRB2-autonomi-launcher/releases).
При запуске лаунчер проверяет, не вышла ли версия новее, и показывает окно с
описанием изменений и кнопками **Обновить сейчас**, **Позже** (спросит при
следующем запуске) и **Пропустить это обновление**. В Настройки → Общие —
«Проверять обновления при запуске», «Проверить обновления» (показывает и
пропущенную версию) и текущая версия.

«Обновить сейчас» скачивает файл для своей системы, проверяет его, заменяет
лаунчер и перезапускает его; запущенная игра продолжает работать. На Windows
не трогаются `user_data` (портативный режим), свой `pointer.txt` и свои
файлы языков. На Linux заменяется AppImage; лаунчер не из AppImage или без
прав на запись в папку открывает страницу загрузки.

## Один лаунчер за раз

Второй запуск выводит на передний план уже открытый лаунчер и закрывается
(два лаунчера мешали бы друг другу). Ключ `--new-instance` открывает ещё один
всё равно.

## Где лежат данные

- Настройки, кэши, темы, копии сохранений и `antd`:
  - Windows: `%APPDATA%\SRB2 Autonomi Launcher\`
  - Linux: `~/.local/share/com.srb2.autonomi_launcher/`
  - в **портативном режиме** — `user_data` рядом с лаунчером: положите рядом
    с `srb2al.exe` (или `.AppImage`) пустой файл `portable` (или
    `portable.txt`).

  Где они сейчас — Настройки → Общие → «Данные лаунчера».
- Журнал — `logs/launcher.log` (прошлый запуск — `launcher.old.log`):
  пригодится, если что-то пошло не так.
- Кэши (`addon_contents_cache.json`, `music/scan_cache.json`,
  `music_render/`) можно удалить — соберутся заново.

## Autonomi (antd)

Аддоны скачиваются через демон Autonomi `antd`
([ant-sdk](https://github.com/WithAutonomi/ant-sdk)). Он идёт вместе с
лаунчером и запускается сам; качать ничего не нужно. Если демон перестал
отвечать, лаунчер перезапускает его сам (не чаще раза в минуту); вручную —
Настройки → Общие → «Перезапустить Autonomi». Если `antd` уже запущен вами
на `127.0.0.1:8082` и отвечает, лаунчер использует его.

## Экономия энергии

- Неизменённые файлы не разбираются заново: аддоны, музыка и отрисованные
  треки берутся из кэша.
- Пока окно свёрнуто, фоновая работа ждёт.
- Анимированные обложки (GIF): все, только выбранная или без анимации —
  Настройки → Аддоны → «Анимированные иконки».
- Группы в «Аддонах» и «Плеере» изначально свёрнуты.
