# Вкладка «Серверы»

[English](servers.md) | **Русский**

## Список

- Серверы берутся с мастер-серверов игры; их списки объединяются. Каждый
  сервер опрашивается напрямую, как это делает игра: название, игроки,
  пинг, карта, режим, версия, список аддонов.
- Столбцы сортируются щелчком по заголовку, имена — с цветами SRB2. Мои
  серверы (★) всегда первые.
- Значки перед именем: флаг страны хоста («?» — неизвестна, «(lh)» — этот
  компьютер), выделенный или обычный сервер, ванильный или с аддонами, читы,
  почему нельзя войти (бан, нет мест, вход закрыт) и «из локального списка».
  Страна определяется по IP по базе внутри лаунчера — адреса никуда не
  отправляются.
- Версия сервера — просто плашка: какая версия игры стоит у вас, лаунчер не
  знает, поэтому серверы другой версии не выделяются.

## Фильтры

My servers, Hide empty, Hide offline (по умолчанию включён), Modified, Hide
local list и выбор режимов (включая режимы из аддонов). В Настройки → Серверы:

- **Скрывать неподдерживаемые серверы** — отвечающие «Unsupported server
  (different game version)»;
- **Скрывать IPv6-адреса** (по умолчанию да) — к ним на деле не подключиться,
  они и не опрашиваются.

Ваши серверы видны всегда.

## Чёрный список

Общий для всех игр. Кнопка рядом со звёздочкой на странице сервера
добавляет в него:

- этот сервер (IP:порт);
- все серверы на этом IP;
- серверы со словом в названии (регистр и цвета не важны).

Такие серверы не показываются, а добавленные по адресу ещё и не
опрашиваются. Список и ручное добавление — Настройки → Серверы → «Чёрный
список».

## Мастер-серверы, свои серверы, локальный список

- **Мастер-серверы** (Настройки → Серверы): название, адрес и состояние,
  переключатель, «Проверить», «Изменить», «Удалить», «Добавить». Адрес —
  ссылка http(s) или `хост:порт` (старые мастер-серверы 2.1).
- **Свои серверы** (кнопка «+» или ★ у сервера) опрашиваются напрямую и
  работают без мастер-сервера.
- **Локальный список**: серверы с мастер-сервера сохраняются и остаются в
  списке (с часами), даже если мастер-сервер недоступен. Срок хранения
  считается от того, когда сервер последний раз ответил: не удалять, месяц,
  неделя, день или не сохранять.

## Вход и аддоны сервера

Аддоны сервера сверяются с папкой игры по имени и контрольной сумме (как это
делает игра). **Подключиться** (или двойной щелчок) сначала скачивает недостающие
аддоны в папку загрузок, затем запускает игру. Источники по порядку:

1. ваши репозитории, если там есть тот же файл (сервер не нагружается);
2. HTTP-зеркало сервера, если оно задано;
3. сам сервер — тем же протоколом, что и игра (если на сервере разрешено
   скачивание и файл не слишком большой).

Не вышло из одного — пробуется следующий. Скачивание можно отменить; кнопка
**Скачать недостающие** качает без запуска и не прерывается при смене
вкладки.

С галочкой «Загружать аддоны в игру до подключения» аддоны сервера
передаются через `-file` в его порядке, и игра подключается без экрана
«Loading addons»; без неё игра загружает их сама. У BlanKart этой галочки
нет: он загружает аддоны сервера только сам.
