# Реплеи (экспериментально)

[English](replays.md) | **Русский**

Вкладка **Реплеи** включается в Настройки → Экспериментальное (по умолчанию
выключена) или в мастере первого запуска. Она показывает `.lmp`-повторы для
**Sonic Robo Blast 2 (2.2)**, **SRB2 Legacy (2.1)**, **SRB2Kart**,
**Dr. Robotnik's Ring Racers** и совместимых форков (например, **BlanKart**),
разбирает карты, персонажей и нужные аддоны и запускает воспроизведение через
`-playdemo`.

## Откуда берутся реплеи

| Игра | Папки игры | Импорт |
|---|---|---|
| SRB2 (2.2) | `data/replay/`, `replay/` | `SRB2AL-Replays/` |
| SRB2 Legacy (2.1) | `replay/` | `SRB2AL-Replays/` |
| SRB2Kart | `replay/` (`kart/`, `online/`) | `SRB2AL-Replays/` |
| Ring Racers | `media/replay/` (`ringracers/`, `online/`) | `SRB2AL-Replays/` |
| BlanKart | `media/replay/` (`online/`) | `SRB2AL-Replays/` |

- Кнопки **С диска...**, **По ссылке...** и перетаскивание `.lmp`-файлов на
  вкладку сохраняют копии в `<папка игры>/SRB2AL-Replays/`, не затрагивая
  штатные папки игры.
- В меню карточки (`⋮`) также доступны **Сохранить копию в SRB2AL-Replays...**,
  **Показать в папке** и **Удалить**.
- Одинаковые файлы одного заезда в одной папке (`-last`, `-time-best`,
  `-lap-best`, `-score-best`, `-rings-best` с тем же размером и контрольной
  суммой) объединяются в одну карточку с бейджами вариантов.

## Аддоны и запуск

- **Встроенный список аддонов** (SRB2 2.2 `demoversion >= 16`, SRB2Kart, Ring
  Racers, BlanKart): лаунчер ищет каждый аддон в папке игры по имени и
  контрольной сумме (MD5 или XXH3-64 у BlanKart):
  - **Зелёная галочка** — на диске найден файл с точным совпадением суммы.
  - **Жёлтая галочка** — на диске найден файл с тем же именем, но другой суммой
    (например, обновлённый официальный пак вроде `bonuschars.kart` в корне
    игры); при запуске лаунчер обновит заголовок реплея.
  - **Скачать** — файла нет на диске, но нужная версия есть в подключённом
    репозитории Autonomi.
  - **Отсутствует** — нет ни на диске, ни в репозиториях; при нажатии **Играть**
    можно скачать недостающие файлы из репозитория или запустить как есть.
- **Старые реплеи без списка аддонов** (SRB2 Legacy 2.1, SRB2 2.2
  `demoversion < 16`): аддон определяется по имени папки реплея через SOC
  `MainCfg → GameData` (например, `kimokawaiii`) или по имени архива; при
  необходимости его можно скачать из репозитория.
- **Доп. аддоны** (кнопка вверху, отдельно для каждой игры): дополнительные
  файлы, которые подключаются после аддонов самого реплея (например,
  `L_SpectatorCamera_V2.3.lua`).
- **Настроить аддоны и запустить...** (меню `⋮`): позволяет включить/отключить
  записанные в реплее аддоны и добавить свои файлы `.lua`, `.pk3`, `.wad`,
  `.kart`, `.soc` на один запуск.
- Когда состав или суммы аддонов отличаются от исходного заголовка, лаунчер
  пересобирает временный `SRB2AL-Replays/temp/replay.lmp` с актуальным списком
  и контрольной суммой (без `-force`); папка `temp/` скрыта из общего списка.
- Кнопка **Играть** со стрелкой позволяет выбрать конкретную сборку игры для
  воспроизведения.
