# Игры

[English](games.md) | **Русский**

Лаунчер поддерживает **Sonic Robo Blast 2** (2.2), **SRB2 Legacy** (форк
2.1), **SRB2Kart** (1.6) и **Dr. Robotnik's Ring Racers** (2.4), а также
**свои игры** — форки, описанные в JSON (например, BlanKart).

Игра выбирается в заголовке окна (вместо названия лаунчера); кнопка с папкой
рядом открывает папку игры. У каждой игры свои папка, очередь запуска,
сборки, параметры, профили, мастер-серверы и список серверов. В списке
аддонов видны только аддоны для выбранной игры — поле `games` в репозитории
(см. [формат репозитория](../manifest-format.ru.md#игры)).

## Какие игры показывать

Настройки → **Игры**: встроенные игры, кроме Sonic Robo Blast 2, можно
выключить — их не будет в переключателе (настройки и файлы остаются). То же
предлагает мастер первого запуска.

## Свои игры

Форки, которые ведут себя как одна из встроенных игр, добавляются из JSON:
при первом запуске — из `another_games.json` рядом с лаунчером (в сборке там
BlanKart; от которой отказались — не добавляется), или в Настройки → Игры →
**Добавить игры из JSON...** (в файле одна игра или несколько — тогда вы
выбираете, какие). Там же свою игру можно выключить, убрать из лаунчера
(файлы игры на диске не трогаются) или экспортировать в JSON вместе с иконкой.
Уже добавленные игры из `another_games.json` обновляются при запуске, если
новая сборка исправила их описание.

Формат описания — в [custom-games.ru.md](../custom-games.ru.md).

## Особенности игр

### Sonic Robo Blast 2

- Папка игры — с `srb2.pk3` (на Linux обычно `~/.srb2`), аддоны скачиваются
  в `DOWNLOAD`; сборка по умолчанию — `srb2win.exe` / `srb2`.
- Мастер-серверы по умолчанию — `https://ds.ms.srb2.org/MS/0` и Weissblatt
  (`https://ms.weissblatt.cc/api/srb2http`).

### SRB2 Legacy

[srb2-preservation/srb2-legacy](https://github.com/srb2-preservation/srb2-legacy)

- Папка игры — с `srb2.srb` (на Linux обычно `~/.srb2_21`), аддоны — в
  `DOWNLOAD`; сборка — `srb2legacywin.exe` / `srb2legacy`.
- Мастер-серверы старого вида — `хост:порт` (TCP, порт 28900):
  `ms.srb2classic.net:28900` и `ms.weissblatt.cc:28900`. Лаунчер получает
  серверы всех комнат и названия комнат.

### SRB2Kart

- Папка игры — с `srb2.srb` (на Linux обычно `~/.srb2kart`), аддоны — в
  `DOWNLOAD`; сборка — `srb2kart.exe` / `srb2kart`.
- Серверы — с мастер-сервера Kart Krew; режимы Race и Battle, без комнат.

### Ring Racers

- Папка игры — с `bios.pk3` (на Linux обычно `~/.ringracers`), аддоны — в
  `addons/DOWNLOAD`; сборка — `ringracers.exe` / `ringracers`.
- Серверы — с мастер-сервера Kart Krew (`https://ms.kartkrew.org/ms/api`).
  Он не присылает имён серверов, поэтому имя появляется после опроса сервера
  и запоминается. Видны средний уровень силы (power level) и режимы
  Race/Battle.

### BlanKart (своя игра)

[NepDisk/blankart](https://codeberg.org/NepDisk/blankart) — форк SRB2Kart.

- Папка игры — с `main.pk3` (на Linux обычно `~/.srb2kart-v2`), аддоны — в
  `addons/DOWNLOAD`, как у самой игры; сборка — `blankart.exe` / `blankart`.
  Видны и аддоны SRB2Kart.
- Серверы — с мастер-сервера `https://ms.blankart.cc/MS/1`. Аддоны с
  сервера качаются заранее, но в игру заранее не загружаются: при
  подключении игра грузит их сама, как велит сервер (иначе игра может
  ответить «You have the wrong addons loaded»).

Как лаунчер разговаривает с серверами каждой игры — в
[internals.ru.md](../internals.ru.md).
