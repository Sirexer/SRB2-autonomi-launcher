# Вкладка «Аддоны»

[English](addons.md) | **Русский**

## Репозитории

- Репозиторий аддонов — JSON-файл, формат — в
  [manifest-format.ru.md](../manifest-format.ru.md). У каждого файла свои
  `version` и `changelog`.
- Подключается кнопкой **Добавить репозиторий** (широкая кнопка над строкой
  поиска): по адресу файла в Autonomi, по **pointer** — изменяемой ссылке на
  файл, — текстом или файлом с диска. При первом запуске лаунчер предлагает
  репозиторий из `pointer.txt` рядом с ним.
- Репозитории по pointer проверяются при каждом запуске: если pointer ведёт
  уже на новый файл, список аддонов обновится — сразу, после вопроса (по
  умолчанию) или никогда (Настройки → Аддоны → «Обновление репозиториев»).
  Кнопка ⟳ рядом с «Добавить репозиторий» проверяет их в любой момент и
  говорит, что обновилось; кнопку ⟳ у каждого репозитория включает Настройки →
  Аддоны (видна, если по pointer подключено больше одного репозитория).
- Если репозиторий с pointer обновили из файла, pointer остаётся, но при
  запуске больше не применяется (значок у репозитория), чтобы не затереть
  файл; по pointer его обновляет кнопка ⟳.
- Репозиторий может советовать скрывать аддоны с некоторыми тегами
  (`hide_tags`). Лаунчер сам добавляет их в скрытые, если включено
  «Автоматически добавлять рекомендуемые к сокрытию теги» (по умолчанию да;
  галочка — в Настройки → Аддоны и в окне «Добавить репозиторий»).

## Версии и файлы

- Если у аддона несколько версий, в карточке есть выбор версии (latest —
  самая новая, downloaded — уже скачанные) и её changelog.
- Файлы версий хранятся раздельно: `DOWNLOAD/<аддон>/<версия>/<файл>`, поэтому
  одна версия не затирает другую. Если на месте файла лежит другой
  (повреждён или изменён вручную), лаунчер спрашивает: заменить, сохранить оба
  или отменить.
- Файлы качаются по одному: пока идёт одно скачивание, «Скачать» у другого
  файла ставит его в очередь (у файла «В очереди» с крестиком). Не скачался —
  очередь идёт дальше.
- Если файлы аддона стоят в очереди запуска, очередь переключается на
  выбранную версию, когда та скачана.
- Если файл не совпал по MD5, в меню «⋮» у файла его можно заменить этой
  версией, удалить, переименовать или переместить.

## Карточка аддона

Название, теги, описание и changelog, затем файлы с проверкой MD5 и кнопками
скачивания, ниже — что внутри скачанных файлов: **режимы игры**, **уровни**,
**персонажи** и **цвета**. Разделы сворачиваются щелчком по заголовку.

- **Уровни**: картинка, имя карты и название из SOC. Без картинки — «?».
  Щелчок по карте добавляет файл в очередь и ставит `-warp <карта>`; в меню
  «⋮» — режимы, которые карта поддерживает (выбор ставит и `-warp`, и
  `-gametype`).
- **Персонажи**: иконка, портрет и описание из меню выбора персонажа.
- Звёздочка добавляет аддон в избранное; кнопка со звёздочкой у поиска
  показывает только избранные.

## Поиск и теги

Условия пишутся через пробел, все должны выполняться.

- `слово` — в названии, категории, у загрузившего и в содержимом файлов
  (карты, режимы, персонажи, цвета), но не в тегах; `-слово` — убрать аддоны,
  где оно есть.
- `группа:тег` — только аддоны с этим тегом (`source:workshop`,
  `content:maps`), `-группа:тег` — без него. Тег совпадает точно; с пробелом —
  в кавычках: `"content:original music"`.
- Группу набирать не нужно: от двух букв под строкой выпадают подходящие теги
  (`work` → `source:workshop`) цветом группы и с числом аддонов.
- Кнопка с ярлыком у поиска открывает все теги игры по группам: щелчок —
  искать с тегом, ещё щелчок — исключить, третий — снять. Группы и их цвета
  задаёт репозиторий (`tag_groups`).
- Теги в карточке аддона — цветом группы, с кнопками ＋ (искать с ним) и －
  (скрыть с ним). Вид тегов (с группой или без, порядок, все сразу или первые
  8) — в Настройки → Аддоны → «Теги на странице аддона».
- Скрытые теги — Настройки → Аддоны → «Скрытые теги».

## Аддоны не из репозиториев

Файлы, MD5 которых не совпал ни с одним файлом репозиториев, показываются
внизу списка:

- **«Другие загрузки»** — из папки загрузок (`DOWNLOAD`, у Ring Racers и
  BlanKart `addons/DOWNLOAD`): скачанные с серверов или самой игрой;
- **«В папке игры»** — из остальной папки игры (например,
  `data/addons/Levels`). Папка обходится, как это делает игра: на 10 уровней
  вглубь, без `screenshots`, `replay` и т.п.; файлы самих игр (`srb2.pk3`,
  `bios.pk3`…) не показываются.

Списки обновляются при переходе на вкладку и после загрузок; кнопка ⟳ в
заголовке раздела ищет новые и удалённые файлы сразу. Каждый раздел
выключается своей галочкой в Настройки → Аддоны, а отдельные папки можно
скрыть в Настройки → Папка игры → «Скрытые папки» (аддоны из репозиториев
видны всё равно).

## Загрузки

Кнопка **Скачивание** в заголовке окна показывает все скачивания — из
репозиториев и с серверов: ход, очередь, ошибки и отмену (начатую загрузку
из репозитория отменить нельзя, ждущую в очереди — можно).
