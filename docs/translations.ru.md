# Переводы

[English](translations.md) | **Русский**

Английский встроен в лаунчер; остальные языки — JSON-файлы в папке `lang`
рядом с лаунчером (`lang/ru.json`, `lang/de.json`...; в репозитории — папка
`lang/`). Сейчас есть русский, украинский (`ua`), немецкий, испанский и
португальский (бразильский, `pt`).

## Как добавить язык

1. Скопируйте `ru.json` в `lang/<код>.json` (`fr.json`, `pl.json`...).
2. Поменяйте `"_language"` на название языка на нём самом (`"Français"`), а
   `"_flag"` — на код страны его флага (`fr`, `br`, `es`...; флаги лежат в
   `assets/flags`).
3. Переведите значения. Ключи — английский текст, их не меняйте.
   Подстановки в фигурных скобках (`{n}`, `{name}`, `{game}`...) сохраните как
   есть, порядок слов вокруг них — любой.

```json
{
  "_language": "Français",
  "_flag": "fr",
  "Settings": "Paramètres",
  "Added {n} file(s) to launch queue!": "{n} fichier(s) ajouté(s) à la file de lancement !"
}
```

- Язык появится в Настройки → Общие и в мастере первого запуска (с флагом).
  Если язык системы совпадает с кодом файла, он выбирается сам при первом
  запуске (украинский: системный `uk` → файл `ua.json`).
- Непереведённые строки показываются по-английски, поэтому файл можно
  переводить по частям.
- Цвета SRB2 в строках (`^2`, `\x82`) не трогайте.

Пришлите файл в репозиторий (pull request), чтобы язык попал в следующий
релиз.
