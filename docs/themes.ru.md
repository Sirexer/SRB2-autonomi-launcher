# Темы

[English](themes.md) | **Русский**

Тема выбирается в Настройки → Общие (и в мастере первого запуска). Кроме
четырёх встроенных, со сборкой идут темы из папки `themes` рядом с
лаунчером: **Ocean**, **Ruby**, **Gold**, **Steel**, **Midnight** (чёрный фон)
и светлая **Daylight**.

## Редактор

**Новая тема** открывает редактор на основе текущей и всегда сохраняет
новую (текущая не меняется), **Изменить** и
**Удалить** — для своих тем, **Папка тем** открывает папку своих тем, ⟳
перечитывает папки. В редакторе справа видно, как выглядит тема.

- **Цвета**: тёмная или светлая, основной цвет (из него строятся все
  оттенки) и, по желанию, точные цвета акцента, фона, панелей и текста.
  Выбор цвета — образцы, оттенок / насыщенность / яркость и HEX.
- **Картинка на фоне**: общая и своя для каждой игры; затемнение, размытие и
  режим — «Растянуть», «Плиткой» (повторяется, как узор на сайте) или «По
  центру» с размером картинки.
- **Шрифт**: шрифт системы (список с поиском, каждый — своим начертанием)
  или файл `.ttf`/`.otf`; размер текста, толщина, интервал между буквами и
  тень текста (цвет, размытие, сдвиг).
- **Углы**: своё скругление кнопок, вкладок, карточек, окон и полей.
- **Окно**: непрозрачность всего окна (на Linux нужен композитный оконный
  менеджер) и подложка Windows 11 — Mica или Acrylic (экспериментально) с
  заливкой: насколько фон темы закрывает размытую подложку (силу размытия
  задаёт Windows).
- **Визуализация музыки**: цвета верха и низа полос.

Свои темы сохраняются в папку `themes` данных лаунчера. Выбранные картинки и
шрифт редактор копирует туда же (`<тема>-<файл>`), поэтому тему можно
передать вместе с ними; удаление темы убирает и их.

## Формат

Тема — JSON-файл. Обязательны `name` и `seed`; остальное строится из `seed`.

```json
{
  "name": "Ocean",
  "dark": true,
  "seed": "#1E5BFF",
  "accent": "#5B8CFF",
  "background": "#0A0F1E",
  "panels": "#111A2E",
  "text": "#E6ECFF",
  "background_image": "ocean.jpg",
  "background_images": { "srb2kart": "kart.jpg" },
  "background_dim": 0.55,
  "background_blur": 4,
  "background_fit": "tile",
  "background_scale": 1.5,
  "font": "Ubuntu",
  "text_scale": 1.1,
  "font_weight": 1,
  "letter_spacing": 0.5,
  "text_shadow": { "color": "#AA000000", "blur": 3, "x": 1, "y": 1 },
  "radius": 14,
  "window_opacity": 0.95,
  "backdrop": "acrylic",
  "backdrop_opacity": 0.3,
  "visualizer": ["#00E5FF", "#2962FF"]
}
```

| Поле | Что это |
|---|---|
| `name` | Название темы. |
| `dark` | Тёмная (`true`, по умолчанию) или светлая. |
| `seed` | Основной цвет: из него строятся все оттенки. |
| `accent` | Точный цвет акцента: кнопки, выделение, текущая вкладка. |
| `background` | Фон окна. |
| `panels` | Карточки, окна, кнопки вкладок. |
| `text` | Цвет текста. |
| `background_image` | Картинка на фоне для всех игр. |
| `background_images` | Свои картинки игр: код игры → картинка. |
| `background_dim` | Насколько фон закрывает картинку: 0–1 (по умолчанию 0.55). |
| `background_blur` | Размытие картинки, 0–40. |
| `background_fit` | `cover` (растянуть, по умолчанию), `tile` (плиткой), `center`. |
| `background_scale` | Размер картинки для `tile` и `center` (1 — как есть). |
| `font` | Название шрифта системы или файл `.ttf`/`.otf`. |
| `text_scale` | Размер текста, 0.7–1.6. |
| `font_weight` | Толщина: от −3 до +3 ступеней. |
| `letter_spacing` | Интервал между буквами. |
| `text_shadow` | Тень текста: `color`, `blur`, `x`, `y`. |
| `radius` | Скругление углов, 0–40. |
| `window_opacity` | Непрозрачность окна, 0.4–1. |
| `backdrop` | Подложка Windows 11: `none`, `mica`, `acrylic`. |
| `backdrop_opacity` | Насколько фон темы закрывает подложку, 0–1 (по умолчанию 0.35). |
| `visualizer` | Цвета полос визуализации: `[верх, низ]` или один цвет. |

- Цвета — `#RRGGBB` или `#AARRGGBB`.
- Пути к файлам — относительно JSON темы.
- Тема, положенная в папку вручную, появится после ⟳ или перезапуска.
- Тема из папки данных важнее темы из сборки с тем же именем файла.
